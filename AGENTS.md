# Projektarbeit

Lies README.md und docs/VALIDATION.md. Hauptziel ist die lokale Windows-Anwendung
AllyLight mit OpenRGB-Anbindung, Hue-Farbquelle und Zomboid-Telemetrie.

Tests: python -m unittest discover -s tests -v
Syntax: python -m compileall -q app.py allylight

Keine Hardware-Schreibtests ohne den fuer diese Sitzung beauftragten Geraeteumfang.
Keine statischen Sicherungen durch aus dem ASUS-SDK gelesene Cachefarben ersetzen.

Keine persoenlichen Profile, Rohberichte oder Bildschirmaufnahmen committen.
Unfertige Eingaben erhalten. Hintergrundereignisse duerfen Formulare nicht ueberschreiben.

realem Nachweis behaupten. Aenderungen auf Arbeitsbranch und als PR bereitstellen.
